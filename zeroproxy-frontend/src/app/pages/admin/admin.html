Connect the camera machine

When the camera recognises a student's face, the machine sends their id and time of arrival:

{{ machineRequest }}

time can be "08:05", "08:05:30" or a full date-time, and must be today. The backend compares it with the student's class: after start time + late minutes it is late.

  • 201: saved; the reply has status (present/late), lateAfter and minutesLate. Late = parents messaged.
  • 200 with alreadyMarked: true: the student was already marked today.
  • 400: missing/invalid id or time. 404: no student has that id.
  • 401: wrong or missing device key.

To test from a terminal: npm run scan -- 2 08:05 in zeroproxy-backend.

Security & privacy

  • Every portal requires a login and only shows data for that role.
  • Camera frames are processed on the device and never stored. Only the attendance result is saved.
  • Parents can only see their own child's records.
  • Teachers only see the classes they are assigned to.
  • Only admins can create or delete accounts and classes.
